<summary>🐍 <b>Como Ativar a Animação da Cobrinha (GitHub Actions)</b></summary>
<br/>

A animação da cobrinha é atualizada automaticamente todos os dias. Para configurá-la no seu repositório:

1. Crie o arquivo `.github/workflows/snake.yml` no seu repositório público `marcos22-s/marcos22-s`.
2. Cole o código YAML abaixo:

```yaml
name: Generate Snake

on:
  schedule:
    - cron: "0 0 * * *" # Executa automaticamente à meia-noite
  workflow_dispatch: # Permite execução manual

jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk@v3
        with:
          github_user_name: marcos22-s
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark

      - uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
